Get music onto a phone by scan-to-join. The **live cluster identity IS the Swarm inviter** — no parallel identity: Auto's `Clustation_concrete` stands up the active `%Identity` with `.c.keys` (ed25519) owning a `%Peering`+`prepub`, exactly what `Swarm_mint_idzeug` consumes; drop the "Idzeug" name user-facing, keep the signed `Swarm_*` verbs. Full design = `spec/Swarm_spec.md §10.1`.

**Compact token IS canonical (2026-07-27):** `<prepub16>*<serial>*<n>*<presig16>` (~48 chars, was 428). `Swarm_token/_parse/_n/_presig` in Swarm.g. Presig = issuer-side MAC `signHeader({prepub,serial,n})` truncated 16 hex; the door REGENERATES from its own ledger record (params from the record, never the carried `$n`) and prefix-matches. **Seal is 3-frame**: `pier_hello` (no grant!) → `pier_accept` (one-sided seal at issuer) → `pier_confirm` (deferred reciprocal, `Swarm_confirmed` handler). **Unknown serial → `refuse('unknown')` LOCALLY, no reply** (serials are guessable — replying confirms the door); spent/held still reply post-presig-proof. `ttl` door REMOVED (no clock — infinite until first claim; SwarmPolicy re-expressed as the no-clock law). Chain lineage keeps the full signed atom on `record.c.iz`.

**?Iz claim arc:** identities carry `born` (yyyy-mm-dd, stamped ONLY by `Clustation_mint` — adopted legacy keys are birthless, never auto-join). A sealed ?Iz claim (`join()`) rewrites `?Iz=…` → `?I=<my prepub>` but **MUST `Clustation_pin` FIRST** — a bare page's default identity is stored under its ROLE tag ('sound'); an unpinned `?I=<prepub>` reload MINTS A STRANGER under that tag (friendship orphaned). A self **born today auto-joins** a landed invite (scan = intent); older identities keep the deliberate JOIN button. A pasted-link row (added 2026-07-27) redeems a token under the enclosing page's `?I` (hidden once a link is landed/parsed; does NOT auto-join). **`strip_iz` (2026-07-28) drops `?Iz` from the URL on EVERY terminal state — spent (refused redeem), complete (sealed), OR a dead/unparseable landed token — not just the old pinned-success path; the pin gates only the `?I=` SET, the `?Iz` DROP is unconditional so a reload never re-presents a dead blob.**

**Presence:** any inbound frame from a sealed pier stamps `pier.c.heard_at` (c-side, never snapped; strangers stamp nothing); the no-payload `pulse` frame (`Swarm_pulse_all`, paced ~5s by `Sounditron_trickle`, never in a Book) exists only to generate it; `%Friend` rows wear `here:1` within a 12s window.

**Presentation:** QR = full-screen face (`min(92vw,80vh)`, opens on mint, click-away closes), TAN not white via qrious white bg + `mix-blend-mode:multiply` over amber-tan. `InviteQR` `padding=16` rides IN the image (scan-safe quiet zone).
