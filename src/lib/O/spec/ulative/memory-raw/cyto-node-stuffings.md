Display-tech build (chosen over Cyto token-travel / center-eruption / texture layers): a particle carrying `stuff:1` (`n.sc.stuff`) renders as one Cytoscape node whose HTML overlay hosts a **live `data/Stuffing` of that particle** — its subtree shown as a compact grouped table inside the node. The user chose **REUSE data/Stuffing in place** (not fork a next-level `O/ui/Stu/` family — that + the "erupt from the middle of the screen" next-version Stuffing stay deferred).

**Wiring (3 in-bounds files; browser-UNVERIFIED — cytoscape can't run headless, Story_cli can't mount it):**
- `Cyto.svelte`: `cyto_nstyle` gains a `n.sc.stuff != null` branch → `{overlay_kind:'stuff', overlay_bg, style:<200×130 host box>}` (no overlay_str). The scan each_fn bakes `overlay_kind` onto the cyto_node even without overlay_str (new `else if (nd.overlay_kind)`). `make_wave` captures the upsert entry and stamps `entry.c.source_n = C.c.source_n` (the LIVE particle) when kind==='stuff' — rides the in-process graph channel on `.c`, never encoded.
- `Cytui.svelte`: `apply()` routes `overlay_kind==='stuff'` to new `create_stuff_overlay(id, nd.c.source_n, bg)` which `mount()`s (Svelte 5) `data/Stuffing` into the overlay div with props `{stuff: source_n, mem: H.imem('cytostuff:'+id), H}`; tracked in `stuff_mounts` map; `unmount()`ed in `remove_overlay`/`clear_all_overlays`. `.stuff-overlay` CSS = pointer-events:all + overflow:auto + top-left align (overrides base .cyto-overlay centering).
- `data/Stuffing.svelte`: register key changed `mem.path` (undefined → collides) → `mem.keys.join('/')` (distinct per node). In-bounds: reads Modusmem.keys, does NOT touch `lib/mostly` (see [[architecture-lib-mostly-legacy]]).

**KEY facts:** House IS the Modus (`H.imem(...)` mints a per-node mem — mirrors Otro's `house.imem('current')`). Stuffings self-refresh via House's one refresh-climb over all registered stuffings (the version poll). source_n already lived on the cyto_node's `.c.source_n` (set in scan); the only gap was ferrying it onto the wave entry.
